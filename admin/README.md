# admin

Мок админки: обзор, ошибки, обращения, донаты, пресеты, группы. Все данные из `src/lib/mock.ts`,
там же наверху — какие события клиент должен слать, чтобы это посчитать на бэке.

Группы — это сервисы каталога движка (`engine/core/presets/catalog.go`): стартовые берутся из
`engine/core/presets/defaults.json`, пресет выдаёт ровно тот JSON-каталог, который принимает
`presets.Parse` (домены и ip везде, приложения и папки по `windows` / `darwin` / `linux`).
Группу, которую движок отверг бы, выпустить нельзя.

```
npm i
npm run dev     # http://localhost:5175
```
