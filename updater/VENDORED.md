# nekko-updater — откуда и как синхронизировать

`nekko-updater/` — крейт из `m1d1x/nekko` (`client-core/nekko-updater`), снят с
коммита `5b1ff719e3aef7026447ac56d465fd404b2f7d82` (2026-10-30).

Hikkari — первый продукт, который выпускает его на Windows, поэтому Windows-половина
дописывается здесь и потом переносится обратно в Nekko. Крейт держим максимально близко к
источнику: любое расхождение — осознанное и перечислено ниже.

## Расхождения с Nekko

| Файл | Что | Почему |
|---|---|---|
| `src/swap.rs` | `apply` и тесты замены собираются на Windows; заглушка «not implemented» удалена | Замена — те же два rename; на Windows их делает процесс, живущий **вне** установки (служба Hikkari рядом с `app\`), после того как всё внутри неё завершилось |
| `src/swap.rs` | Провал **первого** rename удаляет `PENDING.json` | Иначе следующий старт считал бы СТАРУЮ версию «на испытании» и в итоге «откатывался» в пустоту. На Windows это частый случай — файл внутри установки ещё открыт |
| `src/stage.rs` | `check_same_volume` на Windows сравнивает диск/шару и запрещает staging **внутри** установки | В исходнике staging на Windows планировался дочерним; при замене через rename первая же операция унесла бы его вместе с установкой |

Всё это переносимо в Nekko как есть.

## Как обновить из Nekko

```bash
diff -ru ../nekko/client-core/nekko-updater updater/nekko-updater
```

Перенести изменения руками, сохранив расхождения из таблицы; обновить коммит выше.
